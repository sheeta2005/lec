## 1. 题目理解

**问题描述**：
给你一个长度为 n 的数组 nums1，其中包含互不相同的整数。
你需要构造另一个长度为 n 的数组 nums2，使得 nums2 中的元素要么全部为奇数，要么全部为偶数。
对于每个下标 i，你必须从以下两种选择中任选其一（顺序不限）：

- nums2[i] = nums1[i]
- nums2[i] = nums1[i] - nums1[j]，其中 j != i
  如果能够构造出满足条件的数组，则返回 true；否则，返回 false。

**示例**：
> 输入：nums1 = [2,3]
> 输出：true

> 输入：nums1 = [1,4]
> 输出：false

## 2. 解题思路

### 核心观察

题目条件下，所有输入样例均可返回true。

### 算法步骤

1.不做额外判断，直接返回布尔值true。

package lc3875;

        return true;

}
