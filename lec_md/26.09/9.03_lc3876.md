## 0. 前言
- 日期：2026.09.03
- 题目：3876.构造奇偶一致的数组 II
- 难度：中等
- 标签：数组 链表 哈希表


## 1. 题目理解
**问题描述**：
给定互不相同整数的数组nums1，构造等长nums2。每个下标i二选一：nums2[i]=nums1[i]，或者nums2[i]=nums1[i]‑nums1[j] (j≠i)。nums2全部奇数或者全部偶数返回true，否则false。相比I版增加数值大小约束，做减法得到的值必须大于等于1。

**示例**：
>输入：nums1 = [2,3]
>输出：true

>输入：nums1 = [1,4]
>输出：false


## 2. 解题思路
### 核心观察
减法生成的值必须≥1，不能为负数。
若数组最小值是奇数，所有位置都可以构造出奇数，直接返回true。
若数组最小值是偶数，则所有元素本身必须全部是偶数，才可以满足条件。

### 算法步骤
1.记录数组第一个元素的奇偶标记jo，保存初始最小值min。
2.遍历数组剩余元素，更新jo标记（全部元素是否为偶数），同步更新全局最小值min。
3.判断最小值奇偶：最小值为偶数，返回jo；最小值为奇数直接返回true。


## 3. 代码实现
```java

package lc3876;

class Solution {
    public boolean uniformArray(int[] nums1) {
        //奇-奇=偶；偶-偶=偶；偶-奇=奇；奇-偶=奇；
        boolean res = false;
        boolean a = false;
        boolean b = false;
        int qiCount = 0;
        int ouCount = 0;

        int qiMin = Integer.MAX_VALUE;
        int ouMin = Integer.MAX_VALUE;

        for (int i = 0; i < nums1.length; i++) {
            if (nums1[i] % 2 == 0 && nums1[i] < ouMin) {
                ouMin = nums1[i];
            }
            if (nums1[i] % 2 != 0&& nums1[i] < qiMin) {
                qiMin = nums1[i];
            }
        }


        for (int i = 0; i < nums1.length; i++) {
            if (a&&b){
                return res;
            }
            if (nums1[i] % 2 == 0) {
                ouCount++;
                if (nums1[i]-qiMin>=1){
                    qiCount ++;
                }
                else {a=true;}
            }
            if (nums1[i] % 2 != 0) {
                qiCount++;
                if (nums1[i]-qiMin>=1){
                    ouCount ++;
                }
                else {b=true;}
            }
        }
        if (qiCount == nums1.length || ouCount == nums1.length) {
            res = true;
        }

        return res;
    }
}

```


## 4. 代码优化说明

{减少if分支判断，压缩双重循环，合并多组布尔标记变量，利用逻辑与合并条件}

```java
package lc3876;
class Solution {
public boolean uniformArray(int[] nums1) {    
// jo标记数组全部元素是否为偶数
boolean jo = nums1[0]%2==0;
// min保存数组全局最小值
int min = nums1[0];
for(int index =1;index<nums1.length;index++){
// &&短路，只要有一个奇数jo就置false
jo = jo&&nums1[index]%2==0;
//迭代更新最小值
min = Math.min(min,nums1[index]);
}
//最小值为偶数，要求数组全员偶数
if(min%2==0){
return jo;
}
//最小值是奇数，一定可以构造成功
return true;

    }
}
```

## 5. 复杂度分析
时间复杂度：O(n)，n为数组长度，仅单次遍历数组。
空间复杂度：O(1)，仅常数个临时变量。
