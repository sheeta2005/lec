## 1. 题目理解
**问题描述**：
给单链表的头节点 head，反转该链表，返回反转之后的链表头节点。

**示例**：
>输入：head = [1,2,3,4,5]
>输出：[5,4,3,2,1]

## 2. 解题思路
### 核心观察
迭代双指针法，使用prev保存前一个节点，cur代表当前遍历节点，nex暂存cur的后继节点。
每次循环把cur.next指向prev，完成局部反转，之后同步移动prev、cur向后迭代。循环结束prev就是新链表头。

### 算法步骤
1. prev初始化为null，cur指向head，nex用来暂存后继节点。
2. cur不为空时循环：
    1. nex保存cur.next，防止链表断裂丢失后续节点。
    2. 将cur的next指向prev，完成反转。
    3. prev移动到cur位置。
    4. cur移动到nex位置。
3. cur为空，循环结束，返回prev，即为反转后的头结点。

## 3. 代码实现
```java
package lc200_lc299.lc206;

public class Solution {

    public class ListNode {
        int val;
        ListNode next;

        ListNode() {
        }

        ListNode(int val) {
            this.val = val;
        }

        ListNode(int val, ListNode next) {
            this.val = val;
            this.next = next;
        }
    }

    public ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode cur = head;
        ListNode nex = head;
        while (cur != null) {
            nex = cur.next;
            cur.next = prev;
            prev = cur;
            cur = nex;
        }
        return prev;
    }
}
```

## 4. 代码优化说明
{减少if分支判断}
```java
public ListNode reverseList(ListNode head) {
    ListNode prev = null;
    ListNode cur = head;
    while (cur != null) {
        ListNode nextTemp = cur.next;
        cur.next = prev;
        prev = cur;
        cur = nextTemp;
    }
    return prev;
}
```

## 5. 复杂度分析
- 时间复杂度：O(n)，n为链表节点数量，每个节点仅遍历一次。
- 空间复杂度：O(1)，迭代版本仅使用若干指针变量，常数空间。

## 6. 总结
迭代反转链表是链表高频基础题。核心要点：**先保存后继节点，再修改next指针**，避免链表丢失。
优化版本把nex临时变量放到循环内部，消除初始化冗余。
也可以使用递归实现反转链表，递归版本时间O(n)，空间为O(n)来自调用栈，迭代双指针在空间性能上更优。
