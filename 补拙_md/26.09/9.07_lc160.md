# LeetCode 补拙笔记
## 0. 前言
- 日期：2026.09.07
- 题目：160.相交链表
- 难度：简单
- 标签：链表 双指针 哈希表

## 1. 题目理解
**问题描述**：
给出两个单链表头结点headA、headB，找到两个链表相交的起始节点；无相交节点返回null。题目保证链表无环，执行完函数链表原始结构不能被修改。相交指节点内存地址完全相同，不是节点val相等。

**示例**：
>输入：listA = [4,1,8,4,5], listB = [5,0,1,8,4,5]
>输出：返回值为8号节点
>解释：两个链表从节点8开始共用后续节点。

## 2. 解题思路
### 核心观察
方案一（长度对齐法）：先统计两条链表长度，长链表指针先走长度差值步，之后两个指针同步向后移动，第一个相等的节点就是相交点。
方案二（双指针拼接法）：指针a遍历A，走完A之后切换到B；指针b遍历B，走完B之后切换到A。两指针会在相交点相遇；无相交时两者同时走到null。不需要预先统计链表长度。

### 算法步骤
长度对齐法（初始代码思路）
1. 分别遍历链表A、B，统计各自链表长度ca、cb。
2. 将指针重置回两个链表头部。长链表指针先前进二者长度差步数，保证剩余待遍历长度相等。
3. 两个指针同步向后移动，比较引用地址，相等直接返回该节点。
4. 遍历结束没有找到相等节点，返回null。

## 3. 代码实现
```java
package lc100_lc199.lc160;

public class Solution {

    public class ListNode {
        int val;
        ListNode next;

        ListNode(int x) {
            val = x;
            next = null;
        }
    }

    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        ListNode a = headA;
        ListNode b = headB;
        int ca = 0;
        int cb = 0;
        while (a != null) {
            a = a.next;
            ca++;
        }
        while (b != null) {
            b = b.next;
            cb++;
        }
        if (a != b) {
            return null;
        }
        a = headB;
        b = headA;
        if (ca < cb) {
            for (int i = 0; i < cb - ca; i++) {
                a = a.next;
            }
        } else {
            for (int i = 0; i < ca - cb; i++) {
                b = b.next;
            }
        }

        while (a != null) {
            if (a == b) {
                return a;
            }
            a = a.next;
            b = b.next;
        }
        return null;
    }
}
```

## 4. 代码优化说明
{减少if分支判断}
```java
public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
    ListNode pA = headA;
    ListNode pB = headB;
    while(pA != pB){
        pA = pA == null ? headB : pA.next;
        pB = pB == null ? headA : pB.next;
    }
    return pA;
}
```

## 5. 复杂度分析
- 时间复杂度：O(m+n)，m、n分别代表两条链表节点数量。两个指针最多各完整遍历两条链表一次。
- 空间复杂度：O(1)，只使用两个指针变量，常数级额外空间。

## 6. 总结
相交判断**必须对比节点引用地址，不能只对比val值**。
长度对齐法需要两次遍历统计长度，还有分支处理长度差；拼接双指针写法代码极简，消除大量if与for循环。
如果链表存在交点，两个指针会在交点相遇；没有交点，两个指针会同时走到null，循环结束返回null。
哈希集合方案可以存下A链表全部节点，遍历B做匹配，但空间复杂度上升O(m)，面试优先双指针解法。
