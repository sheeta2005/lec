## 1. 题目理解

**问题描述**：
给一个单链表头节点head，判断链表是否为回文链表。回文即链表节点值从前往后读与从后往前读完全一致。是回文返回true，否则返回false。

**示例**：

>
> 输入：head = [1,2,2,1]
> 输出：true
>
>
> 输入：head = [1,2]
> 输出：false

## 2. 解题思路

### 核心观察

初始代码使用栈，把全部节点入栈，栈先进后出，出栈顺序等价链表逆序，依次和原链表对比值。
最优解法：快慢指针找到链表中点，反转后半段链表，前后两半同步比对，空间可以压缩到O(1)。

### 算法步骤

栈版本（初始代码思路）

1. 遍历链表，将所有节点val压入栈中。
2. 再次从头遍历原链表，每遍历一个节点，弹出栈顶元素做数值比对。
3. 一旦数值不相等，直接返回false。
4. 全部比对完成，返回true。

## 3. 代码实现

```
package lc200_lc299.lc234;

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {

    public class ListNode {
        int val;
        ListNode next;

        ListNode() {
        }

        ListNode(int val) {
            this.val = val;
        }

        ListNode(int val, ListNode next) {
            this.val = val;
            this.next = next;
        }
    }

    public boolean isPalindrome(ListNode head) {
        Deque<Integer> deque =new ArrayDeque<>();
        ListNode tn1r=head;
        while (tn1r!=null){
            deque.push(tn1r.val);
            tn1r=tn1r.next;
        }
        while (head!=null) {
            if (deque.pop()!= head.val){
                return false;
            }
            head=head.next;
        }
        return true;
    }
}
```

## 4. 代码优化说明

{减少if分支判断}

```
public boolean isPalindrome(ListNode head) {
    //快慢指针找中点，反转后半链表，O(1)空间
    ListNode fast = head, slow = head;
    while(fast != null && fast.next != null){
        fast = fast.next.next;
        slow = slow.next;
    }
    //反转后半段
    ListNode prev = null, cur = slow;
    while(cur != null){
        ListNode tmp = cur.next;
        cur.next = prev;
        prev = cur;
        cur = tmp;
    }
    //前后两段比对
    ListNode p1 = head, p2 = prev;
    while(p2 != null){
        if(p1.val != p2.val) return false;
        p1 = p1.next;
        p2 = p2.next;
    }
    return true;
}
```

## 5. 复杂度分析

- 栈版本：时间O(n)，空间O(n)，需要栈存储全部节点值。
- 优化快慢+反转版本：时间O(n)，空间O(1)，只操作指针，不申请额外容器。

## 6. 总结

栈实现逻辑直观好写，但占用额外存储空间。
面试优先采用**快慢指针找中点 + 反转后半链表**方案，常数空间。
注意：判断回文对比的是节点val，不是节点引用。
奇数长度链表，后半段会少一个中间节点，比对循环以p2(后半段头)不为空作为终止条件即可。
