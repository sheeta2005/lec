## 1. 题目理解
**问题描述**：
给定链表头节点 head，返回链表环的入口节点；链表无环返回null。pos仅用来描述测试用例，不是入参，做题过程禁止修改链表。

**示例**：
>输入：head = [3,2,0,-4], pos = 1
>输出：返回节点2
>解释：链表环入口为索引等于1的节点。

## 2. 解题思路
### 核心观察
Floyd判圈算法。快慢指针先相遇，相遇之后，一个指针移回链表头部，两个指针同时每次走一步，再次相遇的节点就是环入口。
数学推导：设链表直链长度a，环长b。快慢相遇时，快指针路程 = 2 * 慢指针路程，可以推导出：相遇点到环入口距离 等于 头结点到环入口距离。

### 算法步骤
1. 快慢指针都初始化为head，快指针一次两步，慢指针一次一步，循环寻找相遇点。
2. 如果快指针走到null，代表链表无环，返回null。
3. 当快慢指针相遇，将其中一个指针重置到head。
4. 两个指针都每次移动一步，直到再次相遇，相遇节点即为环入口，返回该节点。

## 3. 代码实现
```java
package lc100_lc199.lc142;

public class Solution {
    class ListNode {
        int val;
        ListNode next;

        ListNode(int x) {
            val = x;
            next = null;
        }
    }

    public ListNode detectCycle(ListNode head) {
        ListNode pos1 = head;
        ListNode pos2 = head;
        while (pos1 != null) {
            pos1 = pos1.next;
            if (pos1 == null) {
                return null;
            }
            pos1 = pos1.next;
            pos2 = pos2.next;
            if (pos1 == pos2) {
                pos2=head;
                while (pos1!=pos2){
                    pos1=pos1.next  ;
                    pos2=pos2.next  ;
                }
                return pos2;
            }
        }
        return null;
    }
}
```

## 4. 代码优化说明
{减少if分支判断}
```java
public ListNode detectCycle(ListNode head) {
    ListNode fast = head;
    ListNode slow = head;
    while(fast != null && fast.next != null){
        fast = fast.next.next;
        slow = slow.next;
        if(fast == slow){
            slow = head;
            while(fast != slow){
                fast = fast.next;
                slow = slow.next;
            }
            return slow;
        }
    }
    return null;
}
```

## 5. 复杂度分析
- 时间复杂度：O(n)，n为链表节点总数。快慢指针遍历链表最多两轮，总操作数线性。
- 空间复杂度：O(1)，仅使用有限指针变量，不额外开辟集合存储节点。

## 6. 总结
141只需要判断是否有环，142需要找到环入口。关键点在于**第一次相遇后，一指针放回头部，同步一步前进，再次相遇就是环入口**。
使用fast、fast.next作为外层循环条件，消除内部多余的null判断if分支。
哈希表解法逻辑简单但是空间复杂度O(n)；双指针 Floyd算法做到常数空间，面试优先写双指针版本。
