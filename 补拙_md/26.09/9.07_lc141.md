# LeetCode 补拙笔记
## 0. 前言
- 日期：2026.09.07
- 题目：141.环形链表
- 难度：简单
- 标签：链表 双指针 哈希表

## 1. 题目理解
**问题描述**：
给定链表头节点 head，判断链表是否存在环。链表存在环的定义为某个节点的next指针可以再次回访到该链表内部节点。若有环返回true，无环返回false。pos仅用来描述用例，不作为函数入参。

**示例**：
>输入：head = [3,2,0,-4], pos = 1
>输出：true
>解释：链表尾部连接到索引为1的节点，链表存在环。

## 2. 解题思路
### 核心观察
快慢双指针（Floyd判圈算法）。快指针每次走两步，慢指针每次走一步。
如果链表存在环，快慢指针一定会在环内相遇；如果不存在环，快指针会先走到null。

### 算法步骤
1. 定义快指针、慢指针，初始都指向头结点。
2. 循环，保证快指针以及快指针的下一个节点不为空。
3. 快指针前进两步，慢指针前进一步。
4. 如果快慢指针相遇，说明存在环返回true。
5. 循环终止代表走到链表尾部，无环返回false。

## 3. 代码实现
```java
package lc100_lc199.lc141;

public class Solution {
    class ListNode {
        int val;
        ListNode next;

        ListNode(int x) {
            val = x;
            next = null;
        }
    }

    public boolean hasCycle(ListNode head) {
        ListNode pos1 = head;
        ListNode pos2 = head;
        while (pos1 != null) {
            pos1 = pos1.next;
            if (pos1 == null) {
                return false;
            }
            pos1 = pos1.next;
            pos2 = pos2.next;
            if (pos1 == pos2) {
                return true;
            }
        }
        return false;
    }
}
```

## 4. 代码优化说明
{减少if分支判断}
```java
public boolean hasCycle(ListNode head) {
    ListNode fast = head;
    ListNode slow = head;
    while(fast != null && fast.next != null){
        fast = fast.next.next;
        slow = slow.next;
        if(fast == slow){
            return true;
        }
    }
    return false;
}
```

## 5. 复杂度分析
- 时间复杂度：O(n)，n为链表节点总数。无环时遍历一遍链表；有环时最多遍历环长+链表直链长度。
- 空间复杂度：O(1)，仅使用两个指针变量，常数额外空间。

## 6. 总结
快慢指针是链表判环最优解法，不需要额外哈希集合存储访问过的节点。循环条件直接校验fast与fast.next，省去循环内部多余空值if判断，代码更加简洁。
如果快慢指针相遇，链表一定存在环；循环退出则代表链表到达末尾，不存在环。
